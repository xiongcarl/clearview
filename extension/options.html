        我的過濾規則

        用 Adblock Plus / uBlock Origin 常見語法寫自己的規則，或直接貼上網域清單。優先於內建清單，白名單仍然最優先。

        —

          支援的語法

          ||ads.example.com^ 封鎖整個網域與子網域；也可以直接寫 ads.example.com 或 hosts 格式 0.0.0.0 ads.example.com。

          ||example.com/ads/*、/banner\d+\.gif/ 依網址或正規表示式封鎖。

          @@ 開頭為放行；@@||example.com^$document 在該網站停用所有網路過濾。

          選項：$script image stylesheet xhr frame media font websocket ping popup third-party first-party domain=a.com|~b.com important match-case，前面加 ~ 表示排除。

          example.com,~shop.example.com##.ad 在指定網站隱藏元素；##.ad 套用到所有網站。也支援 :has-text() 等進階選擇器。

          上限 5,000 行；不支援腳本注入（##+js）與例外元素規則（#@#）。

          在網頁上按右鍵選「隱藏這個元素…」，或從工具列面板直接點選。規則套用於該網站及子網域，最多 300 條。
