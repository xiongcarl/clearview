# Chrome 線上應用程式商店上架資料（草稿）

## 名稱
淨頁 Clearview — 廣告攔截

## 簡短說明（132 字元內）
攔截廣告、追蹤與彈窗廣告，特別照顧台灣與中文網站。右鍵即可隱藏元素，支援自訂規則，資料不離開你的電腦。

## 詳細說明
淨頁讓網頁回到它該有的樣子：安靜、乾淨、載入更快。

● 強力攔截：EasyList、EasyPrivacy、AdGuard 中文、uBlock 修正與 HaGeZi 網域清單，涵蓋國際與台灣、香港、中國網站。
● 影片與反攔截處理：內建網站腳本修正，處理 YouTube 等網站的影片廣告與「請關閉廣告攔截器」提示。
● 防彈窗：攔截彈出式廣告，保留正常的登入與連結跳轉。
● 右鍵隱藏元素：看到漏網廣告，右鍵「隱藏這個元素…」，以後不再出現。
● 我的過濾規則：支援 Adblock Plus / uBlock Origin 常見語法，也可直接貼上 hosts 或網域清單。
● 攔截統計：今天、近 7 天與累計攔截數，以及攔截最多的網站。
● 網站顯示異常？一鍵暫停或使用相容模式，其他網站照常防護。
● 鍵盤快捷鍵：⌥⇧H 選取元素、⌥⇧P 暫停此網站。
● 隱私優先：不收集瀏覽紀錄、沒有「可接受廣告」，設定與統計只存在你的電腦。
● 開放原始碼，GPL-3.0 授權。

淨頁免費提供。如果它幫上忙，歡迎透過擴充功能內的「支持淨頁」贊助開發。

## 單一用途說明（Single purpose）
攔截網頁上的廣告、追蹤器與彈出式廣告，並讓使用者隱藏不想看到的網頁元素。

## 權限說明（Permission justification）
- host permissions（http/https 所有網站）：廣告與追蹤器出現在任何網站，需要在每個網頁上套用過濾規則與元素隱藏。
- declarativeNetRequest：以 Chrome 內建規則引擎攔截廣告請求，不讀取請求內容。
- declarativeNetRequestFeedback：統計每頁攔截數量，只在本機顯示。
- scripting：注入元素隱藏樣式、網站修正腳本（全部隨擴充功能打包，不執行遠端程式碼）與元素選取工具。
- webNavigation：辨識頁面與框架，確保樣式套用在正確的文件，並在換頁時重設該頁的攔截數。
- storage：保存設定、自訂規則與統計。
- alarms：每日清單更新與定期彙整統計。
- contextMenus：右鍵選單「隱藏這個元素」「暫停此網站」。
- 遠端程式碼：無。清單更新只下載純文字網域清單，不下載或執行程式碼。
