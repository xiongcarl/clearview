## 4.3.1：修復正常連結被誤擋

4.3.0 嚴格模式把一般點擊的另開分頁連結一起擋住，會影響郵件、文件及部分網站連結。這是相容性缺陷。4.3.1 保留真實一般點擊及 Enter 所選的目的連結；⌘／Ctrl／Shift 及中鍵照常可用。真實點擊連結時，頁面腳本也能開啟與該連結完全一致的一個 HTTP/HTTPS 目的地；它附帶開出的其他網址和重複視窗仍被拒絕。若腳本已開啟該目的地，會取消同一次點擊的預設開啟，避免重複分頁。

更新後請按 `chrome://extensions` 內本擴充功能的重新載入，再重新整理 Gmail 等已開啟網頁。既有頁面內的舊防護須由重新整理移除。原資料夾更新能保留既有設定。

驗證使用獨立 Chrome 和本機郵件式連結、腳本及框架，未讀取你的 Gmail、未開啟帳戶驗證連結，也沒有登入、提交資料或驗證郵件真偽。並非所有以空白視窗中轉、不同網址或按鈕觸發的登入／付款流程都已支援；這類網站可切換一般模式後重新整理。本版網路清單與權限不變，不以提高測試分數宣稱廣告攔截能力提升。


適用於 Mac Chrome 桌面版，最低 Chrome 121。這版補強繞過腳本防護的彈窗處理，並保留跨清單修正、元件內廣告與手動選取的改善，保留成熟開源引擎、網站修正及可撤回的相容設定，附原始碼及可重現的實測工具。尚未與其他產品做公開網站攔截率比較，不能據此宣稱「史上最強」。

## 4.3 的日常使用改進

- **補上借用框架開窗的漏洞**：嚴格模式增加瀏覽器層後備處理。網站借用空白框架的原生開窗方法時，未取得明確連結操作的新增分頁可自動關閉；4.3.1 保留親自點擊的封閉元件連結；既有頁面不會因此關閉。
- **保留明確的開啟連結操作**：一般點擊、Enter、⌘ 點擊、中鍵、Shift 點擊及 ⌘ Enter 的目的連結只取得一次短期放行。一般文件、封閉元件、重寫過的空白框架及跨來源框架都有真實 Chrome 操作證據。右鍵只暫存所選連結的一個候選目的地；不會全面放行該站的開窗。
- **持續套用網站設定**：來源網站的一般／關閉模式、全域暫停及白名單停用這層清理；嵌入來源的白名單也保留。相容模式仍保留嚴格防彈窗。服務工作者重新啟動會重新觀察已開啟的網頁；等待資源的頁面不必先載入完畢。
- **有限且本機的操作記錄**：連結操作只暫存在記憶體，不上傳、不寫入瀏覽歷史；一般候選約 2.5 秒到期，右鍵候選約 30 秒到期。合併同一次操作的滑鼠與鍵盤事件，避免一個操作意外放行兩個視窗。

**這層是建立後清理，不是保證在開窗前阻止。** 本機實測中，受阻 HTTP 彈窗的伺服器仍收到第一次請求；新分頁可能短暫閃現。保留原有文件開始時的腳本防護，後備處理補上可觀察來源的漏洞。尚未觀察到的文件、來源已消失、保護的瀏覽器頁面、部分連鎖開窗及同分頁跳轉仍有缺口。登入、付款、下載的腳本視窗若受嚴格模式影響，可將該網站改用「一般」並重新載入。

## 4.2.2 的規則與使用體驗改進

- **撤銷過時的廣告放行**：網站修正清單中的跨清單網路 `$badfilter` 現在能撤銷完整相同的來源規則。此快照辨識到兩條 EasyList 放行例外應取消，避免它們繼續蓋過廣告封鎖。一般允許規則不會因這項修正被全面刪除。
- **隨清單開關恢復**：開啟來源修正清單時套用取消；關閉來源清單會恢復目標規則原有行為。重新啟用目標清單時仍沿用來源設定。手動允許、單站暫停與全域暫停保留優先權；單站相容模式仍保留基本廣告過濾。
- **保留修正可追溯性**：取消記錄連到來源文字及原生規則 ID，相關 HEAD 防護與可選直接拒絕對應也一併處理。若原生更新中途失敗，設定交易回復前一組靜態與動態規則。清單維護工具會在暫存重建這份對應，和其他資料一同備份及替換。
- **實際請求證據**：同一本機伺服器、一般網址形式及原生 Chrome 網路過濾，4.2.1 會放行受例外影響的廣告程式，4.2.2 會封鎖且原端點沒有收到請求；正常相鄰程式保留。這是指定上游規則的受控證據，不是所有網站、所有廣告或分數的改善承諾。詳細結果見 `TESTING.md`。

## 4.2.1 的使用體驗改進

- **大量元件更快完成過濾**：減少重複比對及逐個元件的強制版面計算，將新元件的顯示覆寫合併到畫面更新週期。初始自動樣式仍先套入完整規則。
- **補上大量巢狀元件漏網**：探索佇列在合併大量變更時會保留內層工作，也會重新探索封閉元件；一次新增 150 組內外封閉元件，以及元件內稍後建立的子元件，都有驗證。
- **保留重新露出處理**：規則比對依元件現有的 class、ID、標籤找候選，特殊或不確定的選擇器保留原生比對。元件變更時撤銷快取；網站僅改寫 CSS 樣式表時仍有定期檢查。停用後釋放候選快取。
- **4.2.1 當時的實測**：同一台 Mac 的隔離 Chrome、五份清單均開啟，反覆新增 150 個元件的四次量測中位數由 4.2.0 的約 871 ms 降至約 63 ms，正常內容全部保留。兩組各有一次先行暖身；首次頁面過濾時間約 0.5 秒，未觀察到相同程度的加速。這是本機受控元件頁面，不代表所有網站速度或其他產品的表現。原始結果及方法見 `BENCHMARK.md`。

## 4.2 的日常使用改進

- **網站元件內的廣告**：標準廣告隱藏規則現在可套入開放、封閉及巢狀 Shadow DOM，補上普通頁面 CSS 進不去的範圍。動態新增、移除後重插、單頁網站換路由及框架內元件都有驗證。
- **更深入的手動選取**：選取器可點到頂層網頁的開放或封閉元件內元素，保存精確的元件路徑。相鄰元件或文件中同名元素不會因該規則一起消失。
- **補上背景圖橫幅**：標示 sponsored 的圖片連結即使改成背景圖或加上圖片包裝層，也會隱藏；普通背景圖片與純文字連結保留。
- **可撤回的元件過濾**：設定可單獨關閉自動元件隱藏；網站相容模式也停用它。保留網站自己的樣式，移除過濾時恢復本插件改過的行內顯示值；網站後來改成其他顯示值時，會保留新的值。明確保存的手動元件規則另行生效。
- **處理重新露出的廣告**：已追蹤元件的樣式或內容改變後，合併到畫面更新週期重新檢查；適用規則可再隱藏以行內 `!important` 顯示的廣告。未改寫網站的 `attachShadow` 函式。

此功能使用同一文件共享樣式表及分批探索；不會每個元件複製整份清單。既有主機稍後才建立元件，約每 1.5 秒安排檢查；繁忙或背景頁面可能延遲。150 個元件的基本／完整設定實測及限制見 `BENCHMARK.md`，並不代表任何網站都能立即完成。自訂元件規則很多或頁面忙碌時，額外處理仍可能增加。

原有網站白名單、分站防彈窗、手動選取元素、自訂封鎖／允許、本機診斷及設定備份仍可使用。相容網站也會保存並包含在備份中。

新安裝預設啟用五份網頁清單、第三方加強封鎖、網站修正、進階元素辨識、自動元件隱藏及嚴格防彈窗；**直接拒絕相容替代資源預設關閉**。升級保留既有設定。「套用加強攔截模式」會開啟直接拒絕及完整清單，仍保留白名單與相容網站；可能增加反攔截提示或網站異常。

## 安裝與升級

1. 解壓縮 `ad-shield-v4.3.1.zip`。
2. 在 Chrome 輸入 `chrome://extensions`，開啟「開發人員模式」。
3. 按「載入未封裝項目／載入解壓縮」，選取**直接包含 `manifest.json` 的 `ad-shield` 資料夾**。
4. 重新載入已開啟的網頁，從拼圖圖示開啟或釘選「清靜瀏覽」。

已安裝前版時，把新版檔案覆蓋到**原本安裝的資料夾**，保留原路徑。在 `chrome://extensions` 按插件的重新載入按鈕，再重新載入網頁。改用另一個路徑可能被視為另一個擴充功能；避免同時啟用多個版本。Chrome 需要保留該安裝資料夾。一般安裝不需要 Node 或 Python。

此版是本機載入版，未上架商店。只測試 Mac Chrome；Safari／Firefox 不適用。若其他插件佔用 Chrome 的共用規則額度，面板會顯示初始化錯誤，可在進階設定減少啟用的清單。

## 遇到誤擋時

嚴格模式可能影響登入、付款、下載的新視窗；浮層清單也可能隱藏正常社群元件。

- 先試「此網站使用相容模式」並重新載入，保留基本廣告攔截。若已開啟「直接封鎖廣告資源」，此站仍沿用該選項；可在進階設定關閉它，恢復相容替代。
- 「暫停此網站」暫停主機及其子網域的網路、彈窗、元素與網站腳本修正，也涵蓋頁面的 iframe。**重新載入網頁**才能移除已安裝的腳本防護。
- 「恢復此網站」移除涵蓋目前主機的白名單。移除上層條目會讓其其他子網域恢復攔截。
- 需要正常開窗，可為該網站改用「一般」，保留其他攔截。
- 需要特定資源，可將目的網域加入允許名單；它只放行網路請求，優先於清單及自訂封鎖。
- 可分別關閉網站腳本修正、進階元素辨識或自動元件隱藏，協助確認問題來源。

上限：網站相容模式 200、網站白名單 200、自訂封鎖／允許各 500、網站防彈窗模式 50、手動元素規則 300。設定包含子網域，更具體的防彈窗模式優先。瀏覽器內建頁面與 IPv6 網址不提供網站專用設定。

## 防彈窗如何判斷

「一般」只允許近期真實操作的一個腳本視窗，須在 1.5 秒內開啟；背景或模擬點擊不取得放行權限。「嚴格」保留真實點擊／Enter 所選連結，以及同一目的地的一個腳本視窗；背景開窗、額外目的地及新視窗表單仍受限制。⌘／Ctrl／Shift 及中鍵連結操作也保留。「關閉」只停用防彈窗，其他過濾仍可使用。

頂層防彈窗與網站腳本修正在文件開始時注入。iframe 必須先取得頂層網站政策再注入，存在短暫啟動空窗。4.3 的瀏覽器層後備處理可清理部分繞過的新增分頁，仍不能保證擋住所有框架開窗、跳轉或廣告；一般模式也不能知道放行的第一個視窗是否是廣告。

## 元素與網站腳本

標準 CSS 會自動處理符合規則的動態元素。AdGuard ExtendedCss 補上依文字、父層、樣式等條件判斷的規則，並觀察頁面變更；停用或加入白名單後會撤銷其樣式。收錄清單中的 `:remove()` 在本版改為隱藏，便於恢復；保護 HTML／body，避免進階規則將整頁隱藏。

面板的「選取並隱藏網頁元素」讓你在頂層頁面點選、檢查選擇器後確認保存。Enter 確認、Esc 取消。進階設定可手動輸入標準或引擎支援的進階選擇器、移除規則。選取器可深入頂層頁面自己的開放／封閉 Shadow DOM；介面仍不能直接選取跨來源 iframe 內的元素。網站改版後手動規則可能需要重選。

元件手動規則使用 `主機選擇器 >>> 元件內選擇器`，巢狀元件可增加一段 `>>>`。各段只接受標準 CSS，最多 8 段、總長 500 字元；一般文件仍支援原本的進階選擇器。這是本插件的路徑格式，並非瀏覽器原生 CSS。文件規則使用 `@scope` 限定於文件；元件規則另外套入指定根，避免一般規則滲入元件。Chrome 的 [openOrClosedShadowRoot API](https://developer.chrome.com/docs/extensions/reference/api/dom) 提供封閉元件存取，[共享 adoptedStyleSheets](https://developer.mozilla.org/en-US/docs/Web/API/ShadowRoot/adoptedStyleSheets) 承載標準規則；最低 Chrome 121 已支援 [@scope](https://developer.chrome.com/docs/css-ui/at-scope)。

網站腳本修正使用已包入插件的固定函式，依官方 uAssets 快照提供網站條件及參數，可改變廣告相關變數、JSON 及部分請求回應。已確認相容的三參數回應修正別名也納入；不執行任意清單中的 JavaScript。部分上游函式可能修改該站 Cookie／本機儲存；停用並不自動回復這些網站資料。

浮層隱藏不會自動拒絕 Cookie、取消訂閱或變更帳號設定，也不保證處理所有遮罩或恢復捲動。元件內的進階文字／程序規則尚未套入這個新引擎；偽元素及依行內 style 屬性判斷的規則僅使用樣式表，不使用行內強制回寫。持續反覆改寫顯示值的網站、嵌入式特殊內容與反攔截偵測仍可能造成漏網。

## 診斷、備份與隱私

診斷預設關閉，開啟並儲存後重新載入問題網站，可查看最近 200 筆規則命中，包含封鎖、放行及本機替代。可將請求主機加入待儲存的封鎖名單。它不是廣告數統計。

記錄保存在記憶體／Chrome 工作階段儲存，關閉診斷或結束瀏覽器工作階段會清除。URL 省略帳密、查詢參數及片段，但路徑仍可能包含敏感資訊。設定及記錄不會上傳；沒有帳號、分析追蹤或遙測。更新來源伺服器可看到 IP 等一般連線資訊。瀏覽時不下載或執行遠端插件程式碼。

JSON 備份包含自訂網站設定，接受 2.0／3.0／4.0 格式，不包含下載清單。匯入取代個人設定，保留目前清單版本。關閉或移除插件後，重新載入已開啟網頁以清除先前注入的行為。

權限：`storage` 保存設定與清單；`scripting` 及 HTTP／HTTPS 網站權限提供 CSS 與腳本注入；`webNavigation` 核對正在套用規則的分頁／框架頁面身分，確認注入失敗是否因換頁，並接收新增分頁事件執行防彈窗後備清理；不讀取或保存瀏覽歷史；`declarativeNetRequest` 套用網路規則；`declarativeNetRequestFeedback` 提供本機開發模式診斷；`alarms` 排程網域更新。Chrome 可能顯示讀取／變更網站資料的提示。本機替代資源列在 `web_accessible_resources`。

## 驗證與限制

可重現 Mac Chrome 測試：`node tools/test-browser.mjs`。只使用插件下 `testing-output` 內的獨立瀏覽器設定檔，不使用你的日常設定檔；會輸出結果及介面截圖。實際新聞／文件閱讀檢查可用 `node tools/test-reading.mjs reading`；元件檢查用 `node tools/test-components.mjs`；跨清單原生請求與失敗回復檢查用 `node tools/test-static-policy.mjs`；完整設定的元件體驗量測用 `node tools/test-component-performance.mjs`，會保留每次完成時間、正常內容及長任務觀察。公開測試頁檢查用 `node tools/test-public-sites.mjs default`。公開頁面會連線至各網站，不登入帳號、不改動頁面測試或分數。詳細測試範圍、數量及效能資料見 `TESTING.md`、`BENCHMARK.md`。

支援的是網路、腳本與元素語法的子集。網路轉換錯誤、被略過的動作與元素語法、腳本轉換失敗皆記於 `data/web-meta.json` 及 `data/advanced-meta.json`。跨清單 `$badfilter` 目前只取消模式、旗標、選項值及網域集合相同的完整來源規則（支援選項排序與已識別別名）。部分網域取消、擴大集合的等價取消與混合來源的合併規則仍未處理；可辨識的拒絕原因記於 `data/badfilter-policy.json`。同清單仍使用上游轉換器處理。不支援 `redirect-rule`、HTML 回應改寫或任意腳本；無效進階選擇器逐頁略過。網站安全政策可能限制部分腳本效果。

**YouTube 等影片插播仍可能漏掉，不能保證攔截全部廣告。** 本版增加了影片相關上游規則，但受控測試不是公開影片平台驗證。插件也不能移除已授權的系統通知來源或其他 Mac 軟體的廣告，沒有付費產品的客服及跨平台支援。
