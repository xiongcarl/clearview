## 補上的規則
- **彈出視窗規則（`$popup`）3,032 條。** declarativeNetRequest 分不出彈出視窗和一般導覽，轉換器因此整批丟掉
  （光 EasyList 就約 3,000 條）。現在由背景程式處理：頁面開啟新分頁時，用清單比對目標網址，
  符合就關閉；新分頁開啟後 5 秒內的轉址也會檢查。暫停的網站、相容模式的網站，以及彈出視窗設為「關閉」
  時不處理。資料在 `data/engine/popups.json`，由 `tools/build-popups.mjs` 產生。
- **改樣式規則（`selector:style(...)`）685 條。** 清單用它還原網站偵測到攔截後做的事，例如鎖住捲動、
  保留空白區塊。以前全部略過，所以廣告擋掉後頁面可能卡住不能捲。宣告內容不允許大括號、`url()`、`@` 等。
- **`:remove-attr()`、`:remove-class()` 92 條**，轉成同名的 AdGuard scriptlet。
- **過濾清單更新到 2026-11-10**（上一版是 11-01）。
