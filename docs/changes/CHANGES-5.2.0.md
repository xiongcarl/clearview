# 淨頁 Clearview 5.2.0

## 新功能
- **攔截統計**：彈出面板顯示今天與累計攔截數；設定頁新增「攔截統計」，含累計、今天、近 7 天、14 天長條圖與攔截最多的網站，可重設。
- **我的過濾規則**：支援 Adblock Plus / uBlock Origin 常見語法（`||domain^`、網址萬用字元、正規表示式、`@@` 放行、`$script,image,third-party,domain=,important,match-case,document,popup` 等選項，以及 `domain##selector` 元素規則）；可直接貼 hosts 或網域清單。輸入時即時檢查並標示錯誤行號，正規表示式由 Chrome 驗證。
- **右鍵選單**：「隱藏這個元素…」直接選取右鍵點到的元素；「暫停／恢復此網站的攔截」。
- **鍵盤快捷鍵**：⌥⇧H（Alt+Shift+H）選取元素、⌥⇧P（Alt+Shift+P）暫停此網站；可在設定頁變更。
- **元素選取工具**：新增「擴大範圍」，一鍵改選外層容器。
- **歡迎頁**：首次安裝時開啟，說明釘選、右鍵隱藏與相容模式。
- **支持淨頁**：彈出面板、設定頁與歡迎頁的贊助入口，以及達到 1,000／10,000… 攔截數時一次性的感謝提示（只在設定贊助網址後顯示，按「稍後再說」即不再出現）。網址在 `common.js` 的 `SUPPORT_URL` 設定。

## 修正
- 彈出面板的即時攔截數原本每 1.5 秒呼叫一次 `getMatchedRules`，超過 Chrome 每 10 分鐘 20 次的上限後，數字會停住長達 10 分鐘。改為所有畫面共用一個增量查詢並保留配額給背景彙整。

## 上架準備
- 新增 PRIVACY.md（隱私權政策）與 STORE-LISTING.md（商店說明、權限說明草稿）。

## 介面重新設計
- 設定頁改為 claude.ai 設定頁式版面：固定左側欄（圖示導覽、支持淨頁、版本）、置中閱讀欄、浮動儲存列（有未儲存變更時轉為陶土色）。
- 「我的過濾規則」改為對話輸入框式編輯器；統計卡、清單、快捷鍵統一為細線分隔的面板。
- 彈出面板與歡迎頁重新設計；非網頁分頁顯示灰色狀態。
- 修正：Chrome 對擴充功能頁面預設把字體縮成 75%，導致設定頁部分文字過小。
