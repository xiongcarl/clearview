# Ad Shield 4.9.0 — 恢復遺失的網址規則與防誤攔例外

日期：2026-10-23

本版修正實際的清單建置缺陷：所使用的 DNR 轉換器在 Node.js 中仍預設呼叫 Chrome 的正規表示式驗證介面。因建置程序沒有該介面，一批原本可用的網址規則被丟棄；其中也包含用來保留正常圖片／功能的放行規則。

## 改善內容

建置流程現在使用固定版本的 RE2 驗證器，採用上游 CLI 相同的記憶體預算，再以實際 Chrome 驗證產出的規則。不會以 JavaScript RegExp 代替 RE2，也不會移除原規則的網站、第一方／第三方、資源類型及大小寫條件。

五份網頁規則集恢復 **124 條原生規則**：114 條阻止、7 條放行、3 條本機替代。阻止數含 3 條替代資源的 HEAD 防護；可選直接拒絕規則另增加 3 條。放行例外中有 1 條隨預設關閉的干擾清單生效，其餘位於網站修正清單。這些是規則數，不是廣告數、網站數或攔截率百分比。

實際本機請求對照確認：

- 第三方變動路徑廣告腳本、另一種廣告腳本模式及中文網站限定的廣告腳本，舊版可載入，新版會阻止，原端點零請求。
- 相似檔名、同路徑的第一方或不同資源類型，以及其他網站使用相同路徑，依原規則條件保留。
- 恢復的指定網站圖片放行例外可蓋過受控的低優先序衝突規則，不放行其他圖片或其他來源網站。這是例外優先序測試，不聲稱使用者先前遇過該特定誤攔。
- 已有網路規則的條件及動作均保留，優先序的相對排序不變。手動允許、單站暫停及正常頂層導覽仍優先。

保留 4.8.1 的精準廣告元件過濾、商品連結保護與網址邊界修正。預設設定、原生跳轉、Google 登入服務例外、Apple 風格介面與權限不變；不會重新開啟額外服務限制或嚴格防彈窗。這次使用原有上游清單快照重建，沒有將整個服務加入黑名單，也沒有修改測試網站的結果。

## 驗證與範圍

- 13 項 Node 建置檢查：有效封鎖／放行規則保留、條件保留、不支援的 RE2 語法仍拒絕。
- 套件內 130 條正規表示式規則全部通過 Chrome `isRegexSupported` 驗證，包含既有 3 條本機規則與可選直接拒絕規則。
- 31 項 Chrome 專項檢查全數通過；相同工具對照 4.8.1 為 24／31。新增測試針對此次缺陷，並非全網抽樣。
- 224 項瀏覽器回歸、34 項導覽與設定升級、57 項精準過濾及 15 項介面檢查。
- 公開 Guardian／MDN 的攔截開關對照結果另存 `reading.json`，僅核對匿名主內容與文章導覽，不把受阻請求數當廣告數。

原始證據位於 `verification/v4.9.0/`。本機網路測試的主機名稱一律解析到隔離的 loopback HTTPS 假資料；圖片是單像素測試檔，沒有讀取相關網站內容或使用私人帳戶。仍有 RE2 記憶體或其他不支援語法的規則未收錄，沒有為了增加數量強行放寬條件。

實際 Gmail、Google 登入、付款和影片播放未使用使用者帳戶驗證；本版保留既有修復並重新通過受控導覽檢查。不能據此保證所有網站無誤攔，也不能預測公開連線測試分數。

## 安裝

解壓縮 `ad-shield-v4.9.0.zip`。要保留設定，將其中 `ad-shield` 的檔案更新到 Chrome 原先載入的資料夾，再於擴充功能管理頁重新載入。或先停用舊版，再載入新版包含 `manifest.json` 的資料夾；不同位置可能產生不同擴充功能 ID，設定不一定沿用。

確認面板顯示 **4.9.0**，並重新整理網頁。不要同時啟用舊版，也不需要重新套用加強模式。既有總開關、網站暫停及相容設定會保留。新版網址規則隨套件提供，只按面板的「更新廣告清單」不會更新這部分。

## 開發重現

使用固定版本依賴後，執行 `node tools/build-web-filters.mjs` 重建網路規則。一般清單維護流程 `node tools/update-web-lists.mjs --offline` 也會使用修正後的驗證器。轉換器版本改變時會要求檢查驗證器介面，避免再次靜默漏收。

測試工具：`test-node-regex.mjs`、`test-regex-browser.mjs`、`test-browser.mjs`、`test-navigation.mjs`、`test-precision.mjs`、`preview-ui.mjs`，皆位於 `tools/`。瀏覽器測試需要 macOS Chrome、Node.js；HTTPS 專項另需 openssl。`test-regex-browser.mjs 舊版資料夾 --observe` 可記錄舊版對照。

依據：[Chrome DNR 官方 API](https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest)、套件內固定版本 `@adguard/dnr-converter 2.0.0` 的 ESM 與 CLI 實作，以及 `@adguard/re2-wasm 1.2.0`。原有開源來源及授權保留。
