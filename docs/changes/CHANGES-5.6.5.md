# 淨頁 Clearview 5.6.5

## 修正：擴充功能錯誤頁出現「Initialization: TypeError: Failed to fetch」
原因是自用版資料夾被換成 5.6.4 後，Chrome 仍在執行記憶體裡 5.6.3 的程式。5.6.3 的程式去讀 5.6.4 已經改名的
資料檔（`fix-keys.json` → `fix-keys.bin`），讀不到就讓整個初始化回報失敗。已在測試瀏覽器重現。
- 預先登記 YouTube、Twitch 修正的步驟失敗時，不再讓整個初始化失敗。
- 打包工具更新未封裝的資料夾時，改成先覆蓋新檔、最後才刪掉多餘的舊檔，資料夾不會有短暫被清空的時刻。
- 曾試過「發現資料夾版本變了就自動重新載入」，但在測試瀏覽器裡重新載入會讓擴充功能消失，無法確認對真實
  Chrome 是否安全，所以沒有採用。更新自用版後仍需到 `chrome://extensions` 按一次重新載入。

## 攔截：補上 69 條原本被略過的網站修正
uBlock 的 `json-prune-fetch-response`、`json-prune-xhr-response` 用一組具名參數（`propsToMatch`, 網址）指定要處理
哪個請求。通用轉換器會把這組參數丟掉，整條規則因此被略過；另有一種寫法被轉成錯誤的參數，規則永遠不會生效。
AdGuard 版本的同名 scriptlet 用第三個參數表示同一件事，現在直接對應。與 5.6.4 相比新增 88 個網站對應，包括：
- X（Twitter）時間軸、搜尋、回覆裡的推廣推文
- Facebook 的影片插播廣告與側欄贊助內容
- YouTube 手機版、兒童版、無 Cookie 版的 Shorts 廣告
- Target 等購物網站的贊助商品，以及多個串流網站的片頭廣告

`tools/test-list-rules.mjs` 以模擬的 target.com 搜尋請求確認贊助商品被移除；同一測試在 5.6.4 會失敗。

## 量測
- 隱藏元素：31 個能正常載入的真實網站（台灣、中國、英文），與參考引擎（`@ghostery/adblocker`，讀同一批清單）
  逐個元素比對：參考引擎隱藏的 660 個元素全部也被隱藏；多隱藏的只有新浪首頁 2 個 `div[id^="ad_"]` 廣告框。
- 網路請求：5.6.0 時量過與參考引擎 99.8% 一致，這版沒有重量。
- 公開測試：AdBlock Tester 96 分、Turtlecute 130/130，與先前相同。
