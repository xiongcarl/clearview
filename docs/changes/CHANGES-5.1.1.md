# 淨頁 Clearview 5.1.1（2026-11-01）

- **元素選取器重新設計**：改成和面板一樣的風格，支援深色模式。點選元素後可以「重新選擇」，不必取消重來；如果這頁有多個相同元素，會先告訴你一共幾個、會一起隱藏。
- **提前隱藏只在主頁面執行**：iframe 多半是會被網路規則擋下的廣告框，不再讓每個 iframe 都讀一次整份規則。
- 工具列攔截數字預設關閉（5.1.0 已改），可在設定中開啟。

## 這輪檢查過、確認不需要改的地方
- **YouTube 影片廣告**：用兩支有營利的熱門影片測試。沒裝插件時頁面帶有廣告排程資料（`adPlacements`）；裝了插件後這份資料被清空，片頭和片中廣告沒有東西可以播。
- **載入速度**：udn、ETtoday、CNN、Yahoo 的載入時間和總 CPU 時間，與沒裝插件時相近（CNN 因為擋掉大量廣告腳本反而更快）。樣式計算每頁約多 30–60 ms，是約 15,000 條通用元素規則的固定成本。
- **udn 多出的 iframe**：這是 Google 廣告腳本被換成本機空白替代後產生的空殼，不會載入任何內容，數量也不會持續增加。
