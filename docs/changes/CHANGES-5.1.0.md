# 淨頁 Clearview 5.1.0（2026-11-01）

## 攔截
- **多套用 364 條 uBlock 網站修正**：uBlock 的 `rpnt`（替換頁面腳本文字，主要用來消除「請關閉廣告攔截器」）等修正，原本因為名稱不同而完全沒有套用。現在依參數轉換成 AdGuard 對應的實作，只轉換語意完全相同的寫法。跳過的條數從 638 降到 273。實測轉換後的修正能讓反攔截判斷失效，也不會改到沒有符合條件的腳本。
- **廣告更早消失**：通用的元素隱藏規則會預先算好存在本機，網頁一開始載入就套用，不必等背景程式回應。冷啟動實測：頁面解析完成時，舊版 3 個測試廣告都還看得到（約 165 ms 後才隱藏）；新版當下就已隱藏 2 個，剩下 1 個的規則在部分網站有例外，所以照舊走逐頁的精確流程。關閉通用隱藏的網站（約 1,400 個）、白名單和相容模式的網站不會套用這個提前隱藏。
- 新浪首頁殘留的 2 個廣告版位已補上專用規則。

## 誤攔
- **網站元件（Shadow DOM）內只套用該網站的專用規則和少數內建規則**，不再套用整份通用清單。uBlock Origin 也是這樣處理；通用清單是針對一般網頁結構寫的，套進元件裡容易誤藏無關的小工具。

## 介面
- 圖示改為陶土色方塊配白色星芒，小尺寸更清楚。
- 工具列上的攔截數字改為預設不顯示，避免每個網站都跳出數字；面板裡仍看得到。需要時可在「設定 → 防護與彈窗」開啟。

## 驗證
- 測試網站：turtlecute 132/132、adblock-tester 96、superadblocktest 86，與 5.0.0 相同。
- 20 個真實網站：可見廣告框全部為 0（5.0.0 還有新浪 2 個），正文長度沒有變化。
- 專案既有測試全部通過，包括 55 項元件測試。其中一項原本預期元件會收到超過 100 條通用規則，因為這版刻意改變了行為，已更新為「有收到規則」。
