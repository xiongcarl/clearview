# 淨頁 Clearview 5.0.0（原 Ad Shield，2026-11-01）

## 攔截率
- **彈窗廣告網路重新生效**：EasyList／uBlock 中約 640 條「整個網域都是彈窗廣告」的規則，之前被「放行所有頁面導覽」（優先級 1000）蓋掉，彈窗廣告幾乎都會開出來。現在只把這類明確的廣告網域提到 1000 以上；點擊連結、Google 搜尋廣告點擊、郵件追蹤連結、登入跳轉仍照常放行。
- **中文清單換成 AdGuard 中文**（已包含 EasyList China），台灣、香港網站涵蓋更好。AdGuard 語法的網站腳本修正（`#%#//scriptlet`）也會套用。
- **uBlock 修正清單加入 Quick fixes 與 Privacy**：最新的反攔截修正與額外追蹤規則。
- 所有清單更新到 2026-11-01。
- 補上 Taboola／Google 廣告框的殘留隱藏，例如 TVBS 首頁的空白 Taboola 框、Yahoo 新聞頂端的大空白。

## 誤攔
- **加入 uBlock Unbreak 清單**：uBO 官方維護的防誤攔例外，例如保留新聞網站的影片播放器內容。
- 一般模式保留瀏覽器原生跳轉；嚴格防彈窗仍需手動開啟。

## 介面
- 改名為「淨頁 Clearview」，加上正式圖示：陶土色方塊配乾淨頁面與閃亮星（舊版沒有圖示，Chrome 只能顯示名稱第一個字）。工具列的攔截數徽章是綠色。
- 彈出面板與設定頁重新設計，採用 Claude 官網風格（象牙白底、陶土色點綴、襯線標題），支援深色模式與手機寬度。
- 面板顯示「此頁已攔截」數字，工具列圖示也會顯示每頁攔截數。

## 其他
- 每個網頁的元素規則改為快取；同一頁的多個 iframe 不再重複計算。
- 修正診斷紀錄把部分放行規則（導覽、Google 登入、相容模式）標成「封鎖」的錯誤。

## 安裝／更新
把新版檔案覆蓋到原本的 `ad-shield` 資料夾，到 `chrome://extensions` 按重新載入，再重新整理已開啟的網頁。設定與白名單都會保留。
