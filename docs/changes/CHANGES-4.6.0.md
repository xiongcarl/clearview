# 清靜瀏覽 · Ad Shield 4.6.0

2026-10-18。以深石墨與柔和玉綠重設彈出面板和進階設定頁，讓防護狀態、網站操作與進階選項更容易辨識。

## 介面改進

- 重新設計盾牌標誌、字級、細邊框與留白，採一致深色外觀；不載入外部字型或圖片。
- 面板頂部集中顯示整體防護與總開關。啟用、暫停、白名單與相容模式有對應文字及狀態顏色。
- 保留網站暫停、單站防彈窗、元素選取與重新載入操作；相容模式放在「網站顯示異常？」下方，清單及加強選項按需展開。
- 進階設定新增分類導覽及固定儲存列；一般防護設定移到前方，各清單規則數量可展開查閱。
- 提供鍵盤焦點樣式、跳到設定內容連結、減少動畫偏好與窄螢幕排版。

## 驗證與範圍

獨立 Chrome 155.0.8059.80 設定檔完成 12 項介面檢查，包含總開關、單站暫停、相容模式、清單展開、開啟進階設定、儲存、無效輸入、分類導覽與兩種頁面寬度。預設面板內容為 380 × 595 CSS 像素；展開選項或顯示較長提示時可捲動。桌面與 390 像素窄螢幕設定頁沒有水平溢出，並已檢視實際截圖。

4.5.1 的攔截引擎、網路清單、正常連結修復、權限與設定格式保留。本次沒有宣稱提高攔截率，也沒有將截圖中 17 個可連線網域一律封鎖。截圖核對結果見 `SCREENSHOT-REVIEW-2026-10-18.md`，測試紀錄見 `verification/v4.6.0/`；其他版本驗證目錄為歷史紀錄。

## 更新

1. 解壓縮 `ad-shield-v4.6.0.zip`。
2. 備份原本載入的插件資料夾，再將新版 `ad-shield` 內容覆蓋到同一位置。不要先移除原插件，通常可保留原有設定。
3. 到 `chrome://extensions` 按插件的「重新載入」，關閉並重新打開插件面板；已開啟的設定頁也請重新整理。
4. 網頁上的既有攔截程式若需重新載入，請重新整理該網頁。

首次安裝請開啟開發人員模式，選「載入未封裝項目」，選取內含 `manifest.json` 的 `ad-shield` 資料夾。請只啟用一份 Ad Shield。本次沒有改動你的日常 Chrome 設定檔或已安裝插件。

重現介面檢查：在插件資料夾執行 `node tools/preview-ui.mjs`，使用 macOS 的 Chrome 與獨立測試設定檔。
